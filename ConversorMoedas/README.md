# Conversor de Moedas (React Native + Expo)

Como rodar:

1. Crie o projeto base (igual ao vídeo):
   npx create-expo-app@latest conversor-app --template blank
2. Copie para dentro dele: App.js, app.styles.js e a pasta src/ (substitua o App.js).
   Se o template gerou App.tsx, apague-o.
3. cd conversor-app && npx expo start
   (se não conectar no celular: npx expo start --tunnel)
4. Abra o app Expo Go no celular e leia o QR code.

Cotações em tempo real: https://api.exchangerate-api.com/v4/latest/<MOEDA>
